# Algebra — Complete Study Guide

### Exam Paper D1 — Algebra (Products, Factorising, Equations, MCQs)

This exam covers the core Grade 9 algebra skills. Below are the methods, with the memo's worked reasoning and full solutions to the question-only parts.

#### Multiple choice (Q1) — reasoning, not guessing
- 2x − x(x + y): distribute the −x to BOTH terms → 2x − x² − xy (answer B). The leading minus flips both signs.
- 1 is rational, whole and an integer, but NOT irrational (answer C). Irrational = non-terminating, non-recurring decimal.
- A fraction can be a percentage, a decimal and a ratio (answer D) — three ways to express the same fraction.
- √(16x⁴/y¹⁶): root each part by halving exponents → 4x²/y⁸ (answer D).
- Sequence 2; 5; 10; ?; 26 has differences +3, +5, +7, +9, so the missing term is 17 (answer C); equivalently terms = n²+1.
- Ratio 2/5 : 4/6 : 7/15 → common denom 30 → 12:20:14 → ÷2 → 6:10:7 (answer D).

#### Products (Q2.1) — FOIL and patterns
- Distribute: 3x(y + 4z) = 3xy + 12xz.
- Perfect square (a + b)² = a² + 2ab + b²: (2x + 1)² = 4x² + 4x + 1. The two middle terms are always equal.
- FOIL (First, Outer, Inner, Last): (2x − 1)(3x + 2) = 6x² + 4x − 3x − 2 = 6x² + x − 2.
- Keep brackets when subtracting: (2x−5)(x−3) + (x+2)⁰ − (x−2)² = (2x²−11x+15) + 1 − (x²−4x+4) = x² − 7x + 12.

#### Simplifying (Q2.2)
- Dividing by a fraction = multiply by its reciprocal: 10x³ ÷ ½x² = 10x³ × 2/x² = 20x.
- Algebraic fractions: **you can only cancel factors, so factorise first.** (6x² − 24)/(3x² + 6x) = 6(x+2)(x−2) / 3x(x+2) = 2(x−2)/x.
- Add algebraic fractions only when denominators match, then add numerators and simplify at the end (3x/3y → x/y).

#### Perimeter word problem (Q2.3)
Two equal sides 2x² + 2x, perimeter 7x² + 10x. Third side = P − (two equal sides) = (7x²+10x) − (4x²+4x) = 3x² + 6x.

#### Factorising (Q3)
- Common factor: 2x² + 14x = 2x(x + 7).
- Difference of squares a² − b² = (a+b)(a−b): x⁴ − 16 = (x²+4)(x²−4) = (x²+4)(x+2)(x−2). (A sum of squares x²+4 does not factorise.)
- Always take out common factors first: 4x² − 36 = 4(x²−9) = 4(x+3)(x−3).
- Trinomial x² + 7x + 12: find two numbers multiplying to 12 and adding to 7 → 3 and 4 → (x+3)(x+4).
- Grouping with a reversed bracket: (2x−3y)x² + (3y−2x) = (2x−3y)x² − (2x−3y) = (2x−3y)(x²−1) = (2x−3y)(x+1)(x−1).

#### Solving equations (Q4)
- 10 − 3x = 1 → −3x = −9 → x = 3.
- 3(x+2) = 2 − 1(x+4) → 3x+6 = −x−2 → 4x = −8 → x = −2.
- Clear fractions with the LCD: 2x/4 + 1/3 = −4/6 → ×12 → 6x + 4 = −8 → x = −2.
- (2x²+x)/x = (4x²+3)/(2x): simplify LHS to 2x+1, ×2x → 4x²+2x = 4x²+3 → x = 3/2.
- 3(x+2) = 2x²+12+x² simplifies to x²−x+2 = 0, whose discriminant is −7, so there is no real solution.

#### Setting up equations from words (Q4.2, Q4.3)
- Jellybeans: (x+9) + (2x−3) = 2(x+8) → 3x+6 = 2x+16 → x = 10; orange = x+9 = 19.
- Hockey ratio won:lost = 5:1, lost = x+4 → won = 5(x+4) = 5x+20. Total 10x: (5x+20)+(x+4)=10x → x = 6, total = 60.

**Pitfall throughout:** keep brackets when subtracting whole expressions so every sign flips, and always substitute back into the quantity the question actually asks for.
