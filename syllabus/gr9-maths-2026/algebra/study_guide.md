### Exam Paper D1 — Algebra (Products, Factorising, Equations, MCQs)

This exam covers the core Grade 9 algebra skills. Below are the methods, with the memo's worked reasoning and full solutions to the question-only parts.

#### Multiple choice (Q1) — reasoning, not guessing
- 2x − x(x + y): distribute the −x to BOTH terms → 2x − x² − xy (answer B). The leading minus flips both signs.
- 1 is rational, whole and an integer, but NOT irrational (answer C). Irrational = non-terminating, non-recurring decimal.
- A fraction can be a percentage, a decimal and a ratio (answer D) — three ways to express the same fraction.
- √(16x⁴/y¹⁶): root each part by halving exponents → 4x²/y⁸ (answer D).
- Sequence 2; 5; 10; ?; 26 has differences +3, +5, +7, +9, so the missing term is 17 (answer C); equivalently terms = n²+1.
- Ratio 2/5 : 4/6 : 7/15 → common denom 30 → 12:20:14 → ÷2 → 6:10:7 (answer D).

#### Products (Q2.1) — FOIL and patterns
- Distribute: 3x(y + 4z) = 3xy + 12xz.
- Perfect square (a + b)² = a² + 2ab + b²: (2x + 1)² = 4x² + 4x + 1. The two middle terms are always equal.
- FOIL (First, Outer, Inner, Last): (2x − 1)(3x + 2) = 6x² + 4x − 3x − 2 = 6x² + x − 2.
- Keep brackets when subtracting: (2x−5)(x−3) + (x+2)⁰ − (x−2)² = (2x²−11x+15) + 1 − (x²−4x+4) = x² − 7x + 12.

#### Simplifying (Q2.2)
- Dividing by a fraction = multiply by its reciprocal: 10x³ ÷ ½x² = 10x³ × 2/x² = 20x.
- Algebraic fractions: **you can only cancel factors, so factorise first.** (6x² − 24)/(3x² + 6x) = 6(x+2)(x−2) / 3x(x+2) = 2(x−2)/x.
- Add algebraic fractions only when denominators match, then add numerators and simplify at the end (3x/3y → x/y).

#### Perimeter word problem (Q2.3)
Two equal sides 2x² + 2x, perimeter 7x² + 10x. Third side = P − (two equal sides) = (7x²+10x) − (4x²+4x) = 3x² + 6x.

#### Factorising (Q3)
- Common factor: 2x² + 14x = 2x(x + 7).
- Difference of squares a² − b² = (a+b)(a−b): x⁴ − 16 = (x²+4)(x²−4) = (x²+4)(x+2)(x−2). (A sum of squares x²+4 does not factorise.)
- Always take out common factors first: 4x² − 36 = 4(x²−9) = 4(x+3)(x−3).
- Trinomial x² + 7x + 12: find two numbers multiplying to 12 and adding to 7 → 3 and 4 → (x+3)(x+4).
- Grouping with a reversed bracket: (2x−3y)x² + (3y−2x) = (2x−3y)x² − (2x−3y) = (2x−3y)(x²−1) = (2x−3y)(x+1)(x−1).

#### Solving equations (Q4)
- 10 − 3x = 1 → −3x = −9 → x = 3.
- 3(x+2) = 2 − 1(x+4) → 3x+6 = −x−2 → 4x = −8 → x = −2.
- Clear fractions with the LCD: 2x/4 + 1/3 = −4/6 → ×12 → 6x + 4 = −8 → x = −2.
- (2x²+x)/x = (4x²+3)/(2x): simplify LHS to 2x+1, ×2x → 4x²+2x = 4x²+3 → x = 3/2.
- 3(x+2) = 2x²+12+x² simplifies to x²−x+2 = 0, whose discriminant is −7, so there is no real solution.

#### Setting up equations from words (Q4.2, Q4.3)
- Jellybeans: (x+9) + (2x−3) = 2(x+8) → 3x+6 = 2x+16 → x = 10; orange = x+9 = 19.
- Hockey ratio won:lost = 5:1, lost = x+4 → won = 5(x+4) = 5x+20. Total 10x: (5x+20)+(x+4)=10x → x = 6, total = 60.

**Pitfall throughout:** keep brackets when subtracting whole expressions so every sign flips, and always substitute back into the quantity the question actually asks for.


### Algebraic Vocabulary

Algebra has its own language, and getting the words right makes every later topic easier. Learn these carefully.

**Term.** A term is a single number, variable, or a product/quotient of numbers and variables. Terms are separated from one another by + and − signs, and each sign belongs to the term that follows it. In 3x² − 5x + 7 there are THREE terms: 3x², −5x and 7.

**Variable, constant and coefficient.**
- A *variable* is a letter standing for an unknown value (such as x).
- A *constant* is a term that is just a number, with no variable (such as −4).
- A *coefficient* is the number multiplying a variable (the 7 in 7x).

In 7x − 4: the variable is x, the coefficient is 7, and the constant is −4. Note that x on its own has a coefficient of 1, and −x has a coefficient of −1. The sign always travels with the coefficient.

**Like terms.** Like terms have exactly the same variable(s) raised to exactly the same power(s); only the coefficient may differ. So 3x and −5x are like, and 2xy and 7xy are like, but 3x and 3x² are unlike (different powers) and 2x and 2y are unlike (different variables). This matters because ONLY like terms can be added or subtracted when simplifying.

**Classifying by number of terms.**
- Monomial = 1 term, e.g. 5x²y
- Binomial = 2 terms, e.g. 3x − 2
- Trinomial = 3 terms, e.g. x² + 5x + 6

Any expression made of such terms is called a *polynomial*. Just count the chunks split by + and − to classify it.

**Degree.** The degree of an expression is the highest total exponent found in any single term. For a single variable it is the largest power; for a term with several variables, add their exponents.

*Worked example.* Find the degree of 4x³ − 2x²y² + x. Here 4x³ has degree 3; −2x²y² has degree 2 + 2 = 4; and x has degree 1. The highest is 4, so the expression has degree 4.

*Worked example.* In 9 − x + 2x² there are three terms (9, −x and 2x²). The constant term is 9, the coefficient of x is −1 (because −x means −1×x), and the coefficient of x² is 2.

**Common pitfalls.** Forgetting that the sign in front of a term belongs to it; treating −x as if its coefficient were +1; and confusing "like terms" (same variables AND powers) with terms that merely look similar.


### Simplifying Expressions

Simplifying means writing an expression in its shortest equivalent form by collecting like terms and removing brackets.

**Collecting like terms.** Add or subtract the COEFFICIENTS of like terms; the variable part stays the same. Never combine unlike terms.

*Worked example.* Simplify 5x + 3y − 2x + 7y. Group like terms: (5x − 2x) + (3y + 7y) = 3x + 10y. The 3x and 10y cannot be merged because x and y are different variables.

*Worked example.* Simplify 4a² − 7a + 2 + a² + 3a − 5. Collect each type: a²-terms 4a² + a² = 5a²; a-terms −7a + 3a = −4a; constants 2 − 5 = −3. Answer: 5a² − 4a − 3. Write results in descending order of powers, and remember a² and a are UNLIKE, so keep them separate.

**The distributive law.** a(b + c) = ab + ac. Multiply the outside factor by EVERY term inside.

*Worked example.* 3(2x + 5) = 3·2x + 3·5 = 6x + 15. A common error is only multiplying the first term and writing 6x + 5 — the 3 must reach the 5 too.

**A minus sign in front of a bracket** means multiply every inside term by −1, so EVERY sign flips. For example, −(x − 4) = −x + 4. Think of it as −1(x − 4) = −1·x − 1·(−4) = −x + 4.

**Order of operations.** Expand brackets (the multiplication) BEFORE combining like terms — do not subtract numbers that sit outside a bracket first.

*Worked example.* Simplify 2(3x − 1) − 4(x + 2). Distribute each bracket, watching the −4: 2(3x − 1) = 6x − 2 and −4(x + 2) = −4x − 8. Now combine: 6x − 2 − 4x − 8 = (6x − 4x) + (−2 − 8) = 2x − 10. The −4 makes BOTH terms of the second bracket negative.

*Worked example.* Simplify 5 − 2(x − 3) + x. Do the bracket first: −2(x − 3) = −2x + 6, giving 5 − 2x + 6 + x. Collect: −2x + x = −x and 5 + 6 = 11, so the answer is −x + 11 (or 11 − x). Do NOT do 5 − 2 first.

*Worked example.* Simplify x(x + 3) − (x² − 2x). Expand: x(x + 3) = x² + 3x and −(x² − 2x) = −x² + 2x. Combine: x² + 3x − x² + 2x = 5x. The x² terms cancel.

**Common pitfalls.** Forgetting to distribute to every term; mishandling the sign when a minus precedes a bracket; and combining unlike terms such as 3x and 10y.


### Products (Expanding)

Expanding means multiplying out brackets. The key idea is that each term in one bracket multiplies every term in the other, and when you multiply the same base you ADD the exponents (x·x² = x¹⁺² = x³).

**Monomial × polynomial.** Distribute the monomial to every term.

*Worked example.* 2x(3x² − 4x + 5) = 2x·3x² + 2x·(−4x) + 2x·5 = 6x³ − 8x² + 10x.

**Binomial × binomial (FOIL).** FOIL stands for First, Outer, Inner, Last — it simply means each term in the first bracket multiplies each term in the second.

*Worked example.* (x + 3)(x + 5): First x·x = x²; Outer x·5 = 5x; Inner 3·x = 3x; Last 3·5 = 15. Add: x² + 8x + 15.

*Worked example.* (2x − 3)(x + 4) = 2x² + 8x − 3x − 12 = 2x² + 5x − 12. Keep signs with their terms throughout.

**Special product — square of a binomial.**
- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²

Square the first, plus (or minus) twice the product, plus the square of the last. The last term b² is always positive.

*Worked example.* (x + 4)² = x² + 2·x·4 + 4² = x² + 8x + 16. Big pitfall: this is NOT x² + 16 — you must include the middle term 8x.

*Worked example.* (3x − 2)² with a = 3x, b = 2: a² = 9x², 2ab = 12x, b² = 4, so (3x − 2)² = 9x² − 12x + 4.

**Special product — sum × difference (difference of two squares).** (a + b)(a − b) = a² − b². The two middle terms cancel.

*Worked example.* (x + 7)(x − 7) = x² − 49. Checking with FOIL gives x² − 7x + 7x − 49, and the −7x and +7x cancel.

*Worked example.* (2x + 5)(2x − 5) = (2x)² − 5² = 4x² − 25. Remember to square the WHOLE first term: (2x)² = 4x², not 2x².

**Binomial × trinomial.** Multiply each term of the binomial into every term of the trinomial, then collect like terms.

*Worked example.* (x + 2)(x² − 3x + 4): x·(x² − 3x + 4) = x³ − 3x² + 4x and 2·(x² − 3x + 4) = 2x² − 6x + 8. Combine: x³ − x² − 2x + 8.

*Worked example (mixed).* (x + 3)² − (x − 2)(x + 2) = (x² + 6x + 9) − (x² − 4) = x² + 6x + 9 − x² + 4 = 6x + 13. Watch the minus in front of the second bracket: −(x² − 4) becomes −x² + 4.

**Common pitfalls.** Writing (a + b)² as a² + b² (forgetting 2ab); failing to square coefficients; and dropping a sign when a bracket is subtracted.


### Dividing a Polynomial by a Monomial

To divide a polynomial by a single-term divisor (a monomial), divide EACH term of the polynomial by the monomial separately. When dividing the same base, subtract the exponents (x² ÷ x¹ = x¹).

*Worked example.* (6x² + 9x) ÷ 3x. Take each term: 6x² ÷ 3x = 2x (6÷3 = 2, x²÷x = x) and 9x ÷ 3x = 3. Answer: 2x + 3.

*Worked example.* (12x³ − 8x² + 4x) ÷ 4x. Split over each term: 12x³ ÷ 4x = 3x²; −8x² ÷ 4x = −2x; 4x ÷ 4x = 1. Answer: 3x² − 2x + 1. Note the last term divides to 1, not 0 — anything divided by itself is 1.

*Worked example (two variables).* (15a²b − 10ab²) ÷ 5ab. Divide each term by 5ab: 15a²b ÷ 5ab = 3a (15÷5 = 3, a²÷a = a, b÷b = 1) and −10ab² ÷ 5ab = −2b. Answer: 3a − 2b. Matching single powers cancel to 1.

**Fraction-bar form.** A fraction bar means the same as ÷, so you can split the same way.

*Worked example.* (8x³ + 4x²)/(2x²): 8x³/2x² = 4x and 4x²/2x² = 2, giving 4x + 2.

**Common pitfalls.** Dropping a term that divides to 1 (writing it as 0); forgetting to carry the sign of each term; and — most importantly — you may only split a sum or difference over a SINGLE-term denominator. You may NOT split over a denominator that itself has two terms.


### Factorisation

Factorising means writing an expression as a PRODUCT of factors — it is the reverse of expanding. The GOLDEN RULE: always take out a common factor FIRST, then check whether what remains can be factorised further. "Factorise fully" means keep going until no factor can be broken down any more.

**Type 1 — Common factor.** Find the highest common factor (HCF) of the numbers and the lowest power of each common variable, then divide each term by it.

*Worked example.* 6x² + 9x. HCF of 6 and 9 is 3; the common variable (lowest power) is x; so the common factor is 3x. Dividing: 6x²÷3x = 2x and 9x÷3x = 3. Answer: 3x(2x + 3). Check by expanding: 3x(2x + 3) = 6x² + 9x. ✓

*Worked example.* 12a²b − 18ab² + 6ab. HCF of 12, 18, 6 is 6; common variables a and b; common factor 6ab. Dividing gives 2a, −3b and 1. Answer: 6ab(2a − 3b + 1). Don't drop the +1.

**Type 2 — Difference of two squares.** a² − b² = (a + b)(a − b). It works ONLY for a difference (minus) of two perfect squares. A sum of squares such as x² + 25 does NOT factorise.

*Worked example.* x² − 25: here a = x, b = 5, so (x + 5)(x − 5).

*Worked example.* 9x² − 16y²: √(9x²) = 3x and √(16y²) = 4y, so (3x + 4y)(3x − 4y).

*Worked example (fully).* 2x² − 50. Common factor 2 first: 2(x² − 25). The bracket is a difference of squares: 2(x + 5)(x − 5). Pulling out the 2 revealed a difference of squares that was hidden before.

**Type 3 — Trinomial x² + bx + c.** Find two numbers that MULTIPLY to c and ADD to b.

*Worked example.* x² + 7x + 12: pairs of 12 are 1×12, 2×6, 3×4; 3 + 4 = 7, so (x + 3)(x + 4).

*Worked example (signs).* x² − 5x + 6: product +6, sum −5, so both numbers are negative: −2 and −3, giving (x − 2)(x − 3).

*Worked example (mixed signs).* x² + 2x − 15: product −15 (so one + and one −), sum +2; the numbers are +5 and −3, giving (x + 5)(x − 3).

**Type 3b — Trinomial ax² + bx + c.** Multiply a×c, find two numbers that multiply to that product and add to b, split the middle term, then group.

*Worked example.* 2x² + 7x + 3: a×c = 6; two numbers multiply to 6 and add to 7 → 1 and 6. Split: 2x² + x + 6x + 3. Group: x(2x + 1) + 3(2x + 1) = (2x + 1)(x + 3).

*Worked example.* 3x² − 10x − 8: a×c = −24; numbers −12 and +2. Split: 3x² − 12x + 2x − 8. Group: 3x(x − 4) + 2(x − 4) = (x − 4)(3x + 2).

**Type 4 — Grouping (four terms).** Group into pairs, take a common factor from each pair, and arrange so both pairs leave the SAME bracket.

*Worked example.* ax + ay + bx + by = a(x + y) + b(x + y) = (x + y)(a + b).

*Worked example (signs).* x³ + 2x² − 5x − 10 = (x³ + 2x²) + (−5x − 10) = x²(x + 2) − 5(x + 2) = (x + 2)(x² − 5). Factoring −5 out of (−5x − 10) leaves (x + 2), matching the first bracket.

*Worked example (fully).* 3x³ − 27x. Common factor 3x: 3x(x² − 9). The bracket is a difference of squares: 3x(x + 3)(x − 3).

**Common pitfalls.** Trying another method before removing the common factor; trying to factorise a SUM of squares; sign errors in trinomials and grouping; and stopping before the expression is factorised fully.


### Algebraic Fractions

An algebraic fraction is a fraction with variables in it. The golden rule for simplifying is: you may only cancel FACTORS (things multiplied), never individual terms that are added or subtracted.

**Simplifying.** Cancel common factors from top and bottom.

*Worked example.* (6x²)/(9x): numbers 6/9 = 2/3, variables x²/x = x, so the answer is 2x/3.

**Factorise first, then cancel.** When the top or bottom is a polynomial, factorise before cancelling.

*Worked example.* (x² − 9)/(x + 3). Factorise the top (difference of squares): (x + 3)(x − 3). The fraction is [(x + 3)(x − 3)]/(x + 3); cancel (x + 3) to get x − 3. Never cancel the x² or the 9 individually.

*Worked example.* (x² + 5x + 6)/(x² − 4). Top: (x + 2)(x + 3); bottom: (x + 2)(x − 2). Cancel (x + 2) to get (x + 3)/(x − 2).

**Multiplying.** Multiply straight across, but cancel common factors first (you may cancel diagonally across a multiplication).

*Worked example.* (2x/3) × (9/(4x)): cancel 2x/4x = 1/2 and 9/3 = 3, leaving (1/2)×3 = 3/2.

**Dividing.** Dividing by a fraction means multiplying by its RECIPROCAL — keep, change, flip.

*Worked example.* (x/4) ÷ (x²/8) = (x/4) × (8/x²) = 8x/(4x²) = 2/x.

**Adding and subtracting — same denominator.** Just add or subtract the numerators and keep the denominator. Never add the denominators.

*Worked example.* (3x)/5 + (2x)/5 = (3x + 2x)/5 = 5x/5 = x.

**Adding and subtracting — different denominators.** Find the lowest common denominator (LCD), rewrite each fraction over it, then combine the numerators.

*Worked example.* x/2 + x/3. LCD is 6: x/2 = 3x/6 and x/3 = 2x/6, so 3x/6 + 2x/6 = 5x/6.

*Worked example (subtraction).* (2x + 1)/3 − (x − 2)/4. LCD is 12: (2x+1)/3 = (8x+4)/12 and (x−2)/4 = (3x−6)/12. Subtract numerators, keeping the bracket: (8x+4) − (3x−6) = 8x + 4 − 3x + 6 = 5x + 10. Answer: (5x + 10)/12. The minus must flip BOTH terms of (3x − 6).

*Worked example (variable denominators).* 1/x + 2/(3x). LCD is 3x: 1/x = 3/(3x), so 3/(3x) + 2/(3x) = 5/(3x).

**Common pitfalls.** Cancelling terms instead of factors; cancelling before factorising; adding denominators; and forgetting that a subtraction sign in front of a fraction flips every term in its numerator.


### Linear Equations

A linear equation has a variable to the power 1 only. The GOLDEN RULE for solving any equation: whatever you do to one side, you must do to the other, to keep it balanced. Your goal is to isolate the variable using INVERSE operations (undo + with −, × with ÷). Work in reverse BODMAS order — deal with +/− terms first, then the ×/÷ coefficient last.

*Worked example.* 3x + 5 = 20. Subtract 5 from both sides: 3x = 15. Divide both sides by 3: x = 5. Check: 3(5) + 5 = 20. ✓

**Brackets.** Either expand first or divide both sides by the outside factor.

*Worked example.* 2(x − 3) = 10. Option A — expand: 2x − 6 = 10 → 2x = 16 → x = 8. Option B — divide by 2 first: x − 3 = 5 → x = 8. Check: 2(8 − 3) = 10. ✓

**Variable on both sides.** Collect variables on one side and numbers on the other. Move the smaller variable term so the coefficient stays positive.

*Worked example.* 5x − 4 = 2x + 11. Subtract 2x: 3x − 4 = 11. Add 4: 3x = 15. Divide by 3: x = 5.

**Fractions.** Multiply EVERY term by the LCD to clear denominators in one step.

*Worked example.* x/2 + x/3 = 5. LCD of 2 and 3 is 6: 6·(x/2) + 6·(x/3) = 6·5 → 3x + 2x = 30 → 5x = 30 → x = 6.

*Worked example.* (x + 1)/3 = (2x − 1)/5. Cross-multiply (or use LCD 15): 5(x + 1) = 3(2x − 1) → 5x + 5 = 6x − 3 → 5 + 3 = 6x − 5x → x = 8.

**Literal equations (changing the subject).** Treat the other letters just like numbers and use the same balancing rules.

*Worked example.* Make x the subject of y = mx + c. Subtract c: y − c = mx. Divide by m: x = (y − c)/m.

*Worked example.* Make r the subject of P = 2(l + r). Divide by 2: P/2 = l + r. Subtract l: r = P/2 − l (or (P − 2l)/2).

**Common pitfalls.** Doing an operation to only one side; tackling the coefficient before the +/− terms; sign errors when moving terms across; and, with fractions, multiplying only some terms by the LCD instead of every term.


### Quadratic Equations (Solve by Factorising)

A quadratic equation contains an x² term. In Grade 9 we solve them by factorising and using the ZERO-PRODUCT RULE: if A × B = 0, then A = 0 OR B = 0. So first make one side equal to 0, factorise the other side into brackets, then set EACH bracket equal to zero and solve. A quadratic usually gives TWO solutions.

*Worked example.* x² + 5x + 6 = 0. Factorise (two numbers multiplying to 6, adding to 5 → 2 and 3): (x + 2)(x + 3) = 0. So x + 2 = 0 or x + 3 = 0, giving x = −2 or x = −3.

**Common factor (do NOT divide by x).**

*Worked example.* x² = 4x. Move everything to one side: x² − 4x = 0. Factorise: x(x − 4) = 0, so x = 0 or x = 4. Pitfall: dividing both sides by x loses the solution x = 0 — always factorise instead.

**Difference of squares.**

*Worked example.* x² − 9 = 0. Factorise: (x + 3)(x − 3) = 0, so x = −3 or x = 3 (often written x = ±3). Alternatively x² = 9 → x = ±√9 = ±3.

**Harder trinomials (ax² + bx + c).**

*Worked example.* 2x² + 7x + 3 = 0. Factorise (a×c = 6, numbers 1 and 6, split the middle): 2x² + x + 6x + 3 = 0 → x(2x + 1) + 3(2x + 1) = 0 → (2x + 1)(x + 3) = 0. So x = −1/2 or x = −3.

**Rearrange first.** The zero-product rule only works against 0, so move everything across before factorising.

*Worked example.* x² + 2x = 15. Make one side zero: x² + 2x − 15 = 0. Factorise (numbers multiplying to −15, adding to 2 → 5 and −3): (x + 5)(x − 3) = 0, so x = −5 or x = 3.

**Common pitfalls.** Factorising before setting the equation equal to 0; dividing by x and losing a solution; and giving only one answer when a quadratic normally has two.


### Inequalities

Solving a linear inequality is LIKE solving an equation: use inverse operations and keep both sides balanced. There are two differences. First, the answer is a RANGE of values (such as x > 3), not a single number. Second, there is one special rule: whenever you MULTIPLY or DIVIDE both sides by a NEGATIVE number, you must FLIP the inequality sign (< becomes >, ≤ becomes ≥, and so on).

*Worked example (no flip).* 2x + 3 < 11. Subtract 3: 2x < 8. Divide by 2 (positive, so the sign stays): x < 4. The solution is all values less than 4.

*Worked example (flip).* −3x ≥ 12. Divide both sides by −3 and, because it is negative, FLIP: x ≤ −4. Check with x = −5: −3(−5) = 15 ≥ 12 ✓ and −5 ≤ −4 ✓.

*Worked example (flip happens at the right step).* 5 − 2x ≤ 13. Subtract 5: −2x ≤ 8. Divide by −2 and FLIP: x ≥ −4. The flip happens at the divide-by-negative step, not at the subtraction step.

**Number lines.** Draw the line and mark the boundary value.
- Strict < or > → OPEN (unfilled) circle; the boundary is NOT included.
- ≤ or ≥ → CLOSED (filled) circle; the boundary IS included.

Then shade toward the values that satisfy the inequality. For example, x > 2 has an open circle at 2 with shading to the right, while x ≥ 2 has a closed circle at 2 with shading to the right.

**Compound inequalities.** An inequality like −1 ≤ x < 3 means x ≥ −1 AND x < 3 at the same time. Draw a closed circle at −1 (included), an open circle at 3 (excluded), and shade between them. If x is restricted to integers, the solutions here are −1, 0, 1, 2.

**Common pitfalls.** Forgetting to flip the sign when multiplying or dividing by a negative (the most common error); flipping at the wrong step (only at the negative multiply/divide); and using the wrong circle type (open vs closed) on the number line.


### Word Problems

Word problems ask you to turn a sentence into an equation, solve it, and answer in words. Follow these steps:

1. Let a variable (such as x) represent the UNKNOWN you want.
2. Write the other quantities in terms of x.
3. Translate the words into an EQUATION.
4. Solve the equation.
5. Answer the question in words and CHECK that it makes sense.

Useful keyword translations: "sum" → +, "difference" → −, "product" → ×, and "is" or "equals" → =.

*Worked example (number).* I think of a number, multiply it by 5 and subtract 7; the result is 28. Let the number = x. Translate: 5x − 7 = 28. Add 7: 5x = 35. Divide by 5: x = 7. Check: 5(7) − 7 = 28. ✓

*Worked example (consecutive numbers).* The sum of three consecutive numbers is 72. Let the first = x; consecutive numbers go up by 1, so they are x, x+1, x+2. Equation: x + (x+1) + (x+2) = 72 → 3x + 3 = 72 → 3x = 69 → x = 23. The numbers are 23, 24, 25. Check: 23 + 24 + 25 = 72. ✓

*Worked example (ages).* Sam is 4 years older than Thabo, and together they are 30. Let Thabo = x; then Sam = x + 4. Equation: x + (x + 4) = 30 → 2x + 4 = 30 → 2x = 26 → x = 13. Thabo is 13 and Sam is 17. Check: 13 + 17 = 30. ✓

*Worked example (perimeter).* A rectangle is 3 cm longer than it is wide, and its perimeter is 26 cm. Let width = x; length = x + 3. Perimeter = 2(length + width): 2(x + 3 + x) = 26 → 2(2x + 3) = 26 → 4x + 6 = 26 → 4x = 20 → x = 5. Width = 5 cm, length = 8 cm. Check: 2(5 + 8) = 26. ✓

*Worked example (quadratic).* The product of two consecutive positive integers is 56. Let the integers be x and x+1. Equation: x(x + 1) = 56 → x² + x − 56 = 0. Factorise: (x + 8)(x − 7) = 0 → x = −8 or x = 7. The integers must be positive, so x = 7, and the numbers are 7 and 8. Check: 7 × 8 = 56. ✓

**Common pitfalls.** Not clearly defining the variable; mistranslating keywords; forgetting to express the second quantity in terms of x; giving only the value of x instead of answering the actual question; and (in quadratic problems) keeping an answer that the context rules out, such as a negative integer where only positives make sense.
